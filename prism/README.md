# PRISM

An original wavetable synthesizer (AU + Standalone) for one Intel Mac running
Logic Pro. See `SPEC.md`, `PHASES.md`, `CLAUDE.md`, and `PROGRESS.md` for the
results of every phase.

## Build on the Mac (Intel, macOS 11+)

```bash
git submodule update --init --recursive
cmake -S . -B build -G Xcode
cmake --build build --config Release --target PRISM_AU PRISM_Standalone PrismTests PrismBench
```

`COPY_PLUGIN_AFTER_BUILD` installs the AU to `~/Library/Audio/Plug-Ins/Components/PRISM.component`.
(Ninja works too: `cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release`.)

## Checks

```bash
lipo -archs ~/Library/Audio/Plug-Ins/Components/PRISM.component/Contents/MacOS/PRISM   # x86_64
auval -v aumu Prsm Ashr
tools/get_pluginval.sh
tools/pluginval.app/Contents/MacOS/pluginval --strictness-level 10 --validate-in-process ~/Library/Audio/Plug-Ins/Components/PRISM.component
build/Release/PrismTests              # (Xcode generator puts binaries under Release/)
build/Release/PrismTests "[slow]"     # long tests: aliasing sweep, denormals, stress, randomize x500
build/Release/PrismBench init 10      # also: idle, heavy
```

If Logic doesn't list PRISM: `killall -9 AudioComponentRegistrar`, then rescan in
Logic Pro > Settings > Plug-in Manager.

## Factory presets

Generated by `python3 tools/make_factory_presets.py`, then loudness-balanced with
`PrismTool normalize Presets/Factory -16`. They are embedded through BinaryData.

## Layout

- `Source/DSP` — headless DSP (wavetables, oscillators, filters, envelopes, LFOs, FX)
- `Source/Engine` — voice manager, modulation, arp/chord, table manager, import/export, formula parser
- `Source/Params`, `Source/State` — parameter registry, presets, state, randomizer
- `Source/GUI` — editor
- `Tests` — Catch2 suite, benchmark, dev tool
